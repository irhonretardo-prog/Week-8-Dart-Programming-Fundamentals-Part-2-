# Week-8-Dart-Programming-Fundamentals-Part-2-

A Dart application demonstrating core control-flow structures, functional modularity, and runtime error handling to support technical interview readiness and baseline competency development.

- Name: Irhon Clark A. Retardo
- Section: BSIT - 3.3

## Features

- **Conditional Logic:** Evaluates order totals to calculate eligibility for perks and discounts using `if/else` statements.
- **Loops:** Uses a `for` loop to generate an itemized breakdown for each item in the order.
- **Functions & Parameters:** Includes modular functions that accept parameters and return computed values (`calculateTotal`).
- **Error Handling:** Wraps potential runtime exceptions and bad inputs in `try/catch` blocks to ensure graceful degradation.
